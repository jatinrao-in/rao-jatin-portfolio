## 🎨 Theme & Aesthetic
An interactive **dossier/detective case file** themed developer portfolio website. Built with modern web standards and customized for high performance, smooth animations, and maximum readability.

### 🌟 Key Features
- 🔦 **Interactive Blackout Mode:** Click the "Main Breaker" switch to toggle a dark room spotlight effect that follows your cursor.
- 📐 **Dynamic shadows:** Element shadows realistically curl and shift based on real-time mouse coordinate offsets.
- 🗂️ **Case File Tabs:** Seamless tab system detailing Summary, Background, and Arsenal without visual lag.
- 🏷️ **Scroll-Fade Header:** Hero section automatically slides out of view during scrolling to prevent layout overlap.
- 🌐 **Responsive Design:** Optimized for both mobile viewports and large desktop screens.

---

## ⚙️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Fonts:** Playfair Display, Courier Prime, Caveat, Inter
- **Hosting:** Vercel

## 📦 Getting Started

### Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/jatinrao-in/rao-jatin-portfolio.git
   ```
2. Navigate to project:
   ```bash
   cd rao-jatin-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) on your browser.
